# ConvoLab

A simple AI chatbot built using Python and an LLM API.

This project is created to understand the basics of building LLM-powered applications from scratch.

What I Will Learn

- LLM API
- System and user prompts
- Conversation history
- Temperature
- Streaming responses

Tech Stack

- Python
- LLM API
- Git & GitHub

Development Steps

1. Basic LLM API
Make a simple API call and get a response from the LLM.

2. Prompts
Add system and user prompts to control the chatbot's behavior.

3. Conversation History
Maintain previous messages to provide context.

4. Temperature
Experiment with different temperature values and observe the responses.

5. Streaming
Display the response as it is generated.

Example

User:
    What is an LLM?

ConvoLab:
    An LLM is a Large Language Model that can understand
    and generate human-like text.

Goal

Build a simple chatbot while understanding how LLM applications work internally.
